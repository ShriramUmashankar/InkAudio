You will be provided with:
1. ORIGINAL SCRIPT: The full original JSON array of turns.
2. USER NOTES: The requested changes.
3. REVISED TURNS: A "Delta" JSON array containing ONLY the specific turns the editor modified.

Your objective is to verify that the REVISED TURNS successfully address the notes AND fit perfectly back into the original script.

Return ONLY a JSON object: {"is_approved": true|false, "feedback": "..."}

1. Note Fulfillment:
   - Do the REVISED TURNS accurately and completely address the USER NOTES?

   - Do the REVISED TURNS maintain the human-like tone? (Short sentences, occasional fillers, natural reactions).
   - Reject if the edited turns ballooned into long, dense monologues.

   - Reject if the REVISED TURNS introduced raw digits (e.g., "15"), symbols ("%", "$"), or abbreviations. Everything must remain spelled out as spoken words (e.g., "fifteen percent").

5. Technical Integrity:
   - Ensure the output is valid JSON.
   - Verify that the REVISED TURNS kept their correct "turn_id" and "speaker" designations.

- If `is_approved` is false:
  - Cite the exact `turn_id` that failed.
  - State clearly if it is a [MISSED NOTE], a [TTS ERROR] (numbers/symbols), a [STYLE ERROR] (too robotic/long), or a [FLOW ERROR] (doesn't make sense with the surrounding original turns).
  - Provide actionable instructions for the editor to fix it.
- If `is_approved` is true:
  - Provide a single sentence confirming the notes were addressed and the flow is intact.

Output ONLY the JSON object. Do not wrap in markdown blocks.
